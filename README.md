# `mamdous@localhost:~$`

This is my personal portfolio, built around the way I like to work: from a
terminal.

I spend most of my time in the shell - reading documentation, exploring
codebases, solving problems, building projects, and learning how software
works. So instead of making the terminal a decoration, I made it the starting
point. The homepage opens with an interactive shell and the rest of the site
keeps the same straightforward, developer-focused feel.

**Live site:** [mamdous.dev](https://mamdous.dev)

## What is inside

- An interactive terminal-style introduction
- Commands for my background, skills, projects, contact details, and socials
- A few terminal utilities and hidden easter eggs to discover
- Responsive sections for about, skills, projects, and contact
- A lightweight static site with no framework or build step

Try these commands on the homepage:

```text
help
about
skills
projects
neofetch
ls
social
```

## Built with

- HTML5 for the structure
- CSS3 for the terminal-inspired interface
- Vanilla JavaScript for the terminal and interactions
- JetBrains Mono and Inter
- Font Awesome icons

No heavy tooling, no unnecessary abstraction - just files I can open, edit,
and run from the terminal.

## Project layout

```text
.
├── index.html          # page content
├── css/style.css       # styles and design tokens
├── js/terminal.js      # commands and terminal behavior
├── js/main.js          # navigation, scroll effects, contact form
└── favicon.svg
```

To add a terminal command, edit the `commands` object in
[`js/terminal.js`](js/terminal.js).
